## Overview

**KSA Office IT Support & Infrastructure Operations** is a practical, end-to-end IT support portfolio designed around a simulated office environment in Saudi Arabia.

The project covers the complete IT support lifecycle, beginning with business and infrastructure planning and progressing through asset planning, network design, Cisco implementation, Windows administration, Linux administration, IT support operations, and professional technical documentation.

The work combines **hands-on configuration, administration, troubleshooting, incident handling, evidence collection, and documentation** to demonstrate how an IT Support environment can be planned, implemented, maintained, and supported in a structured manner.

---

## Business Problem

A growing office environment requires reliable IT infrastructure and a structured support function to ensure employees can work efficiently and consistently.

Without standardized IT processes, organizations may experience:

- Poorly planned IT infrastructure
- Inconsistent device and asset management
- Network connectivity issues
- User and access management problems
- Windows and Linux administration challenges
- Unstructured troubleshooting
- Poor incident documentation
- Inefficient support escalation
- Incomplete onboarding and offboarding processes
- Lack of standardized IT documentation

This project addresses these challenges by establishing a structured IT support and infrastructure environment covering both **technical implementation and operational support**.

---

## Project Objectives

- Plan an office IT environment according to business requirements.
- Design and implement a structured network infrastructure.
- Configure and manage Windows-based systems.
- Administer Ubuntu/Linux systems using command-line tools.
- Implement structured IT support and incident-management workflows.
- Troubleshoot common hardware, software, network, access, and service issues.
- Maintain IT assets and user/access information.
- Develop standardized IT support procedures and documentation.
- Produce evidence-based technical reports and resolution records.
- Demonstrate an end-to-end IT Support Operations workflow.

## Commands Reference

The project involved practical command-line administration and troubleshooting across Linux and IT support operations.

| Category | Command | Purpose | Working / Expected Result |
|---|---|---|---|
| Navigation | `pwd` | Display the current working directory | Shows the absolute path of the current location |
| Navigation | `cd <directory>` | Change the working directory | Moves to the specified directory |
| Filesystem | `ls` | List files and directories | Displays directory contents |
| Filesystem | `ls -l` | Display detailed file information | Shows permissions, ownership, size, and timestamps |
| Filesystem | `tree` | Display directory structure | Shows files and folders in a tree format |
| Filesystem | `find . -type f` | Find files recursively | Lists files under the current directory |
| Files | `cat <file>` | Display file contents | Prints the contents of a text file |
| Files | `nano <file>` | Create or edit a text file | Opens the file in the Nano editor |
| Files | `mkdir -p <path>` | Create directories | Creates the requested directory structure |
| Files | `touch <file>` | Create an empty file | Creates the specified file |
| Files | `cp` | Copy files/directories | Creates a copy of the specified item |
| Files | `mv` | Move or rename files | Moves or renames the specified item |
| Files | `rm` | Remove files | Deletes the specified file |
| Permissions | `chmod` | Modify file permissions | Changes read/write/execute permissions |
| Ownership | `chown` | Change file ownership | Changes the owner/group of a file |
| Ownership | `chgrp` | Change group ownership | Changes the group associated with a file |
| Users | `whoami` | Display current user | Shows the currently authenticated user |
| Users | `id` | Display user/group identity | Shows UID, GID, and group memberships |
| Users | `who` | Display logged-in users | Shows active user sessions |
| Users | `last` | Review login history | Displays recent login sessions |
| Processes | `ps` | Display running processes | Lists active processes |
| Processes | `pstree` | Display process hierarchy | Shows parent/child process relationships |
| Processes | `top` | Monitor processes/resources | Displays live process and resource usage |
| Processes | `htop` | Interactive process monitoring | Provides an interactive process/resource view |
| Processes | `kill` | Terminate a process | Sends a signal to the specified process |
| Processes | `killall` | Terminate matching processes | Sends a signal to processes matching a name |
| Services | `systemctl status` | Check service status | Displays the current state of a systemd service |
| Services | `systemctl start` | Start a service | Starts the specified service |
| Services | `systemctl stop` | Stop a service | Stops the specified service |
| Services | `systemctl restart` | Restart a service | Restarts the specified service |
| Services | `systemctl enable` | Enable service at boot | Configures a service to start automatically |
| Services | `systemctl list-units` | List systemd units | Displays loaded units and their states |
| Logs | `journalctl` | Query systemd logs | Displays system/service log entries |
| Logs | `journalctl -u <service>` | View service-specific logs | Displays logs for the specified service |
| Logs | `journalctl -n 20` | View recent logs | Shows the most recent log entries |
| Storage | `df -h` | Check filesystem capacity | Displays disk usage in human-readable form |
| Storage | `du -h` | Estimate file/directory usage | Displays storage consumption |
| Storage | `lsblk` | Display block devices | Shows disks and partition information |
| Network | `ip addr` | Display network interfaces/IP addresses | Shows interface and IP configuration |
| Network | `ip route` | Display routing table | Shows configured routes |
| Network | `ping` | Test network connectivity | Sends ICMP requests and reports responses |
| Network | `ss` | Display network sockets | Shows listening/active network connections |
| Network | `netstat` | Inspect network connections | Displays network connection information where available |
| DNS | `nslookup` | Test DNS resolution | Queries DNS for the specified name |
| DNS | `resolvectl status` | Review DNS configuration | Displays resolver and DNS status where supported |
| Network Path | `traceroute` | Trace network path | Displays hops toward a destination |
| System | `hostname` | Display system hostname | Shows the machine hostname |
| System | `hostnamectl` | View/manage hostname information | Displays system hostname and related information |
| System | `uname -a` | Display kernel/system information | Shows kernel and system details |
| System | `date` | Display system date/time | Shows the current system date and time |
| Packages | `apt` | Manage Ubuntu packages | Installs, updates, or removes packages |
| Remote Access | `ssh` | Establish secure remote shell access | Connects to an authorized SSH service |
| File Transfer | `scp` | Securely transfer files over SSH | Copies files between authorized systems |
| Search | `grep` | Search text for patterns | Returns matching lines |
| Search | `grep -E` | Search using extended patterns | Performs pattern-based text filtering |
| Search | `head` | Display beginning of output/file | Shows the first lines |
| Search | `tail` | Display end of output/file | Shows the last lines |
| Scripting | `echo` | Print text/output | Writes the specified text to standard output |
| Scripting | `bash` | Execute Bash commands/scripts | Runs commands using the Bash shell |

> **Note:** Commands containing placeholders such as `<service>`, `<directory>`, or `<destination>` must be replaced with the appropriate authorized value before execution.
